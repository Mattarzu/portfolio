ALLFICTION Portfolio API

API serverless del portfolio para contacto, AF Intelligence y healthchecks, ejecutada en Cloudflare Workers con validación, control de origen y secretos fuera del frontend. Serverless portfolio API for contact, AF Intelligence and health checks, running on Cloudflare Workers with validation, origin controls and secrets kept out of the frontend.

Cloudflare Workers JavaScript Serverless Telegram API AI Gateway Antes Contact Worker Formerly Contact Worker

Problema Problem

El frontend del portfolio, servido desde AWS Lightsail, requiere procesar formularios y habilitar capacidades dinámicas como AF Intelligence sin exponer tokens de bots, credenciales de proveedores ni mantener infraestructura de servidor dedicada. The portfolio frontend, hosted on AWS Lightsail, needs to process form submissions and enable dynamic features like AF Intelligence without exposing bot tokens, provider credentials or maintaining dedicated server infrastructure.

  • Recepción y validación de mensajes públicos con entrega segura a Telegram. Reception and validation of public messages with secure delivery to Telegram.
  • Gateway para AF Intelligence interactuando con el proveedor de IA configurado. Gateway for AF Intelligence interacting with the configured AI provider.
  • Protección estricta de secretos y control de orígenes permitidos (CORS). Strict secret protection and allowed-origin controls (CORS).

Arquitectura Architecture

La solución desacopla la capa de presentación servida en AWS Lightsail de los servicios backend mediante un Cloudflare Worker que centraliza validación, ruteo y secretos: The solution decouples the presentation layer served on AWS Lightsail from backend services using a Cloudflare Worker that centralises validation, routing and secrets:

  • POST /contact: sanitización de payload, validación de campos y entrega directa vía Telegram. POST /contact: payload sanitisation, field validation and direct delivery via Telegram.
  • POST /ai-chat: gateway seguro para AF Intelligence con límites de cuota y contexto del portfolio. POST /ai-chat: secure gateway for AF Intelligence with quota controls and portfolio context.
  • GET /health: verificación pública del estado operativo del servicio y del estado del proveedor de IA. GET /health: public verification of service operational status and AI provider status.
  • Secretos y credenciales gestionados exclusivamente en la configuración del Worker, fuera de Git y del frontend. Secrets and credentials managed exclusively in Worker configuration, kept out of Git and the frontend.

El estado operativo del servicio puede verificarse en vivo mediante su endpoint público de healthcheck. The operational status of the service can be verified live through its public health check endpoint.
